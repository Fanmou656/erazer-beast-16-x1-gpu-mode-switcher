## 📊 What’s Under the Hood? (For the Curious)

This tool works by sending a special command to your laptop’s embedded controller (EC) chip. This chip controls how the display is routed. In simple terms: it flips a hardware switch inside your laptop that tells the screen to connect directly to the NVIDIA GPU instead of going through the Intel GPU first. This is called **"MUX switch"** (short for multiplexer. Your laptop has this hardware capability, but Medion doesn’t provide a simple software toggle for it—until now.

.



The tool is written in PowerShell, which is a built-in Windows scripting language. That means it doesn’t require installation, it doesn’t modify system files permanently, and it doesn’t install background services. It simply sends one command, you restart, anda you’re done.
